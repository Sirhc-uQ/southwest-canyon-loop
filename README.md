# 美国西南峡谷环线

从拉斯维加斯出发，串联大峡谷南缘、马蹄湾、羚羊峡谷、纪念碑谷，以及犹他州多个国家公园的自驾环线。

## 地图

打开 [docs/index.html](docs/index.html) 查看交互地图、地点标记、分段车程与导航链接。也可在仓库根目录运行 `python3 -m http.server 8765 -d docs`，然后访问 `http://localhost:8765/`。

地图沿用 Oregon 项目的 Leaflet 方式。底图由 OpenStreetMap 提供，需要联网；连接线只表示地点顺序。车程为常规路况下的规划粗估，不包含游览、休息、拥堵或公园内驾驶时间，出发前请以实时导航为准。
